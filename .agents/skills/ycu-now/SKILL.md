# /ycu-now — 今すぐ監査する

学生が「今すぐ確認したい」と言ったときに、監査を1回実行して結果を伝える。定期監査の時刻を待たない。定期監査が OFF でも実行できる。流れは定期監査と同じで、**ログイン → 全講義の教材・テスト・課題の差分チェック → （ダウンロードが ON なら）対象講義の資料を保存 → （メールが ON なら）結果メール** を行う。

## 進め方のルール
- 学生が頼んだ時点で実行してよい（確認の質問を重ねない）。ただし、下の「1. 実行前に見ておくこと」に当てはまるときだけ、先に一言伝える。
- **設定は変えない。** 設定を変えたいと言われたら `/ycu-config` を案内する。
- パスワードをチャットで聞かない・表示しない。承認など本人の操作が必要なら案内する。
- コマンドはリポジトリのルートで実行する。1〜3分かかる（講義数による）ことを先に伝える。

## 1. 実行前に見ておくこと
```powershell
python -m src.main --status
```
次の場合だけ、実行前に学生へ伝える。

| 状況 | 伝えること |
|---|---|
| **初回監査が未実施**（「初回監査 未実施」） | 「まだ初回監査をしていません。今実行すると、すでに公開されている資料は『差分』ではなく基準として記録されるだけです（ダウンロードが ON なら対象講義の資料が全部保存されます）。先に `/ycu-config` の初回監査をおすすめします。このまま実行しますか」 |
| Teams が ON で、初回監査が未実施 | Teams も同様に、今あるファイルが基準として記録される（ダウンロードが ON なら全部保存される。写真が多い講義では数十件）。先に初回監査をおすすめする |
| ダウンロードが ON で、保存対象の講義がある | 「新しい資料があれば、対象講義の分は PC に保存されます」（実行の前の一言で足りる） |
| ログインに不安がある（最終実行が「ログイン失敗」） | 先に `/ycu-resume` を案内する |

どれにも当てはまらなければ、そのまま実行する。

## 2. 実行する
```powershell
python -m src.main --now
```
- 設定に従う: ダウンロードは `--status` の「自動ダウンロード」、メールは「結果メール」の設定どおり。
- 学生が頼んだ場合のオプション:
  - メールを送らない → `--no-mail`
  - ダウンロードが OFF だが今回だけ保存したい → `--with-download`（保存先は `output/`）。講義を絞る場合は `--course "講義名"`
  - 画面を見ながら実行したい → `--headful`

ログインに失敗したら、`/ycu-resume`（または `python -m src.main --login`）を案内する。承認が必要な場合は、画面の番号を学生がスマホで入力する。

## 3. 結果を伝える
画面に出力された内容（メールと同じ）を、学生に分かりやすく要約する。

- **更新なし** → 「確認しました。新しい資料・テスト・課題の更新はありません」（確認した講義の数と時刻を添える）。
- **教材の新規・更新** → 講義名、資料タイトル、ファイル名、登録日。保存したものは**保存先のパス**も伝える（`output/<講義名>/<資料タイトル>/`）。
- **Teams の講義資料**（`--status` の「Teams の資料」が ON のとき）→ 「Teams:」欄と「■ 講義名（Teams）」に、新規・更新・削除のファイルが出る。保存したものは `output/<講義名>/Teams/…`。チームが無い講義は出ない（対象外）。録画（`Recordings`）は保存しない。
- **テスト・課題の更新** → 「講義Aでテスト:第3回…が追加されました（解答期間 …）」の文をそのまま伝える。**保存も提出もしていない**ので、大学の画面で確認するよう添える。
- **エラー** → 内容を伝え、原因の候補を1つ示す。ログインなら `/ycu-resume`、特定の講義だけなら再実行（`--now`）を提案する。繰り返すなら `logs/ycuboard.log` を確認する。
- **メール** → 最終行に「結果メールを送信しました」「送りませんでした（理由）」が出る。送信に失敗したときは、ログイン状態（`--check-login`）を確認すると伝える。
- 「講義を初めて確認したので記録だけ行った」と出た講義は、差分としては通知されない。次回から差分が出る、と伝える。

## 4. 続きの提案（必要なときだけ）
- 保存したい資料があるのにダウンロードが OFF／対象外だった → `/ycu-config`。
- 定期監査が OFF で、自動で確認したい → `/ycu-config`。
- 「止まっている気がする」→ `/ycu-resume`。

## 使うコマンド
| 目的 | コマンド |
|---|---|
| 今すぐ監査 | `--now`（`--once` と同じ） |
| メールを送らない／今回だけ保存する | `--no-mail` / `--with-download [--course "講義名"]` |
| 事前に設定を見る | `--status` |
| ログイン確認・復旧 | `--check-login` / `--login` |
