# /ycu-cloud — クラウド（Google Drive など）への保存設定

`output/` に保存した資料を、PC につないだクラウドドライブの**指定フォルダにも同じ構成で複製**する。**初回監査・定期監査（`--now` を含む）のたびに**、足りない分だけコピーする。ON / OFF を切り替えられる。

仕組み: Google Drive for Desktop のようなアプリが、PC に `G:` や `H:` などのドライブ（同期フォルダ）を作る。このツールはそのフォルダにファイルをコピーするだけで、クラウドへの送信はアプリが行う。**Google のログインや認証設定は要らない。**

## 進め方のルール
- 学生が頼んだ時点で始めてよい。**複製先のフォルダは学生に聞く**（勝手に決めない）。どのドライブか分からないときは、ドライブの一覧を見せて選んでもらう。
- **ドライブやフォルダの中身を読まない・一覧しない。** 確認するのはドライブ名と、複製先に書き込めるかだけ。
- 設定は `config.json` を直接編集せず、`python -m src.main --…` で反映する（入力の検証が入る）。
- 設定を ON にする前に、書き込みテストと、保存される内容の確認を行う。永続的な変更（ON）は、学生の了承を得てから行う。
- パスワードは扱わない。Google Drive for Desktop が起動してログインしていることは、学生に確認してもらう。
- コマンドはリポジトリのルートで実行する。

## 1. 今の状態を見る
```powershell
python -m src.main --status
python -m src.main --list-drives
```
- `--status` の「クラウド保存」が ON / OFF か、複製先が設定済みかを確認する。
- `--list-drives` に、つながっているドライブが出る（例: `H:\  メールアドレス - Google Drive`）。**Google Drive など、クラウドのドライブが見えない場合**は、Google Drive for Desktop をインストール・起動してログインしてもらう（見えるようになるまで先へ進まない）。複数ある場合（例: 個人用と学校用）は、**どのアカウントに保存したいか**を学生に聞く。

## 2. 複製先のフォルダを決める
学生に「**クラウドのどのフォルダに保存しますか**」と聞く（例: `H:\マイドライブ\講義資料`）。
- Google Drive の日本語環境では、`マイドライブ` というフォルダがドライブ直下にある。英語環境では `My Drive`。**存在するかどうかだけ**確認する。
- 絶対パスで指定する。フォルダがまだ無ければ、初回のコピー時に作られる。
- **`output/` の中は指定できない。** 共有ドライブや他人と共有しているフォルダを指定する場合は、中身が共有されることを伝えて確認する。
- 学生が「あとで教える」と言ったら、ここで止めて終了する（設定は変えない）。

```powershell
python -m src.main --set-cloud-dir "H:\マイドライブ\講義資料"
```
スペースや日本語を含むパスは `"…"` で囲む。

## 3. 書き込みテスト
```powershell
python -m src.main --test-cloud
```
複製先に小さなテストファイルを書いて読み戻し、消す。`OK` なら次へ。`NG` の理由で分岐する。
- 「ドライブに接続できません」→ Google Drive for Desktop が起動・ログインしているか確認してもらい、もう一度。
- 「コピー先が未設定です」→ ステップ 2 に戻る。
- その他（権限・容量など）→ メッセージを伝え、別のフォルダを選んでもらう。

## 4. ON にする
1. 学生に伝えて了承を得る: 「保存した資料が、`output/` と `<複製先>` の両方に入ります。**今ある資料もまとめてコピーされます**（件数・容量は `output/` の分）。以降は、監査のたびに新しい分・更新された分だけコピーします。」
2. `python -m src.main --cloud-on`
3. すぐに試したいときは、`python -m src.main --now --no-mail` を実行する（`output/` の全部が初回にコピーされるので、時間がかかることを伝える）。結果の最後に「Google Drive へのコピー: N 件」が出る。または、次の定期監査まで待つ。
4. `--status` の「クラウド保存」が ON で、複製先が正しいことを見せて確認する。

## 5. OFF にする・変える
- 止める → `python -m src.main --cloud-off`（複製先に作ったファイルは消えない。設定した複製先は残る）。
- 複製先を変える → ステップ 2 から（`--set-cloud-dir` を新しいフォルダで。**古い複製先のファイルは移動しない**。新しい複製先には、`output/` 全部が次の監査で複製される）。

## 結果の見方・困ったとき
- 監査の結果（画面とメール）に「Google Drive へのコピー: N 件 (<複製先>)」が出る。
- コピーが失敗しても、巡回は止まらず、エラーとして報告される。**失敗した分は、次の監査で自動で補われる。**
- 「ドライブに接続できません」→ Google Drive for Desktop が起動しているか、PC がオンラインか確認する。
- Drive に増えない → `--status` の「クラウド保存」が ON か、複製先が合っているか、`--test-cloud` が OK か。同期アプリのアイコンで、同期が止まっていないかも確認してもらう。
- 複製先のファイルは、このツールは消さない（`output/` から消したものも複製先に残る）。

## 使うコマンド
| 目的 | コマンド |
|---|---|
| 状態を見る | `--status` / `--list-drives` |
| 複製先を決める | `--set-cloud-dir "フォルダ"`（絶対パス） |
| 書き込みテスト | `--test-cloud` |
| クラウド保存 ON / OFF | `--cloud-on` / `--cloud-off` |
| 今すぐ複製する | `--now --no-mail`（監査のついでに複製される） |

（`--drive-on` / `--drive-off` / `--set-drive-dir` は、上と同じ意味の別名。）
